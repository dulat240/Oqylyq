# Oqylyq
Oqýlyq — это современное веб-приложение, которое превращает чтение книг в увлекательный процесс с элементами спорта и геймификации. Подобно тому, как Strava помогает отслеживать пробежки и тренировки, Oqýlyq помогает отслеживать каждую сессию чтения, анализировать прогресс, ставить личные рекорды и соревноваться с друзьями.
